Transformer API¶

Transformer module for time series aggregation.

Provides rolling window and string-based aggregation tools:

  • RollingAggregator: Rolling, expanding, or EWM window aggregations.

  • StringAggregator: Time-window aggregation for categorical/string data.

RollingAggregator¶

class sentinel.transformer.RollingAggregator(window_size, aggregation_functions='mean', columns=None, window_type='fixed', min_periods=None, center=False, suffix='_rolling', **kwargs)[source]¶

Bases: BaseEstimator, TransformerMixin

Rolling aggregate transformer for scikit-learn pipelines.

Computes rolling, expanding, or exponentially weighted moving window aggregations on time series data.

Parameters:

  • window_size (int) – Size of the rolling window.

  • aggregation_functions (Union[str, Callable, List]) – Functions to apply. Can be a pandas rolling method name, a callable, or a list of either.

  • columns (Union[str, List[str], None]) – Columns to aggregate. If None, all numeric columns are used.

  • window_type (str) – One of 'fixed', 'expanding', or 'ewm'.

  • min_periods (Optional[int]) – Minimum observations required. Defaults to window_size.

  • center (bool) – Whether to center the window.

  • suffix (str) – Suffix appended to new column names.

  • **kwargs – Extra arguments passed to the rolling function.

transform(X)[source]¶

Transforms the input DataFrame by applying rolling, expanding, or exponentially weighted moving (EWM) window aggregations to specified columns.

Parameters:

X (DataFrame) – The input DataFrame to transform. If not a DataFrame, it will be converted to one.

Returns:

A transformed DataFrame with new columns containing the results of

the specified window aggregations.

Return type:

DataFrame

Raises:

  • ValueError – If specified columns are not found in the input DataFrame.

  • ValueError – If an invalid aggregation method is specified for the chosen window type.

Notes

  • The columns to be aggregated can be specified via self.columns. If None, all numeric columns in the DataFrame will be used.

  • The type of window (rolling, expanding, or EWM) is determined by self.window_type.

  • Aggregation functions are determined by self._get_aggregation_list().

  • Additional parameters for the window operations can be passed via self.kwargs.

  • The resulting column names will include the original column name, the suffix specified in self.suffix, and the aggregation function name.
