Explorer API¶

Explorer module for signal validation and data quality diagnostics.

Provides tools for assessing whether a dataset contains meaningful signals before investing in anomaly detection pipelines.

Key components:

  • SignalDiagnostics: Programmatic data quality and signal checks.

  • Thresholds: Configurable quality thresholds.

  • QualityReport / CheckResult: Structured result objects.

  • detect_anomalies: IQR-based anomaly detection (standalone function).

  • detect_drift: Statistical drift detection.

  • load_and_label: CSV loading with optional event labeling.

Bases: object

Quick signal diagnostics for anomaly detection datasets.

Parameters:

  • df (DataFrame) – Input DataFrame to diagnose.

  • columns (List[str]) – Numeric columns to analyze.

  • label_column (Optional[str]) – Name of the binary label column (0/1). If None, label-dependent checks are skipped.

  • timestamp_column (Optional[str]) – Name of the timestamp column.

Examples

>>> import pandas as pd
>>> df = pd.DataFrame({"a": range(100), "b": range(100)})
>>> diag = SignalDiagnostics(df, columns=["a", "b"])
>>> diag.summary()
